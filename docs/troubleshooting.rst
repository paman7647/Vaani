Troubleshooting
===============

Quick answers to common problems.

No Microphone Input
-------------------

- Check system input device settings and microphone permissions.
- Close other apps that may lock the microphone.

Recognition Fails
-----------------

- Ensure the correct model is installed and referenced.
- Verify sample rate and audio format compatibility.

No Audio Output
---------------

- Confirm output device selection and volume.
- Test TTS engine separately; switch voices if needed.

Network Features Not Working
----------------------------

- Verify internet connectivity and DNS resolution.
- Confirm API keys and endpoints if integrations are enabled.

Performance Issues
------------------

- Reduce logging verbosity and close background apps.
- Choose smaller speech models or disable nonessential features.

Still Stuck?
------------

- Review :doc:`debugging` for deeper diagnostics.
- File an issue with logs and steps to reproduce.
